# CS110 Action 11B – The Development Road

## My Direction

For this project, I decided to join a lead. Our team is called DufAyzO, and Lexxie is our team leader. My role is to contribute my gaming experience, help come up with ideas, and give feedback on how the game should work.

## The Mission I Want to Explore

Our game is called StimuLye. It is a psychological puzzle-adventure game where the player controls NaN, a character exploring the memories of someone in a coma.

The game starts in complete darkness. As the player explores and interacts with objects called Stimuli, the environment slowly becomes clearer.

I think this concept is interesting because it encourages players to explore and figure things out instead of having the game explain everything.

## My Contribution

I want to help the team make the gameplay interesting and understandable. Since I enjoy playing video games, I can contribute ideas about how players interact with the environment, how puzzles work, and how the game responds to their actions.

## My Attention Accord

My focus is understanding how we can turn our game's story into actual gameplay.

I want to explore how the player interacts with memory objects and how those interactions change the environment.

My goal is to help the team create something that is interesting to play while keeping the first prototype simple enough to build and test.

## My Story-to-Code Plan

One object we could create is a glowing memory orb.

The orb would be a GameObject in Unity with a C# script attached to it.

The script could check when the player gets close enough to interact with the orb. When the player interacts with it, the orb could disappear and reveal an object connected to the character's memories.

This would help connect the story to something the player can actually do.
